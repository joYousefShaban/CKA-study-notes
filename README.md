## 🗺️ Background

My learning path leading up to CKA:

1. **CKAD Certification** – Foundation in workloads, services, and application-level K8s.
2. **LFS258 – Kubernetes for Absolute Beginners / Kubeadm** (foundation for cluster administration)
3. **Mumshad Mannambeth's CKA course** (exam-focused, hands-on labs)
4. **Hands-on Practice** – Drilling through cluster-specific question banks.
5. **Killer.sh** simulator + mock exams.
