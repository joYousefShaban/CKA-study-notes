## Caveats

- “Unique” means **not a dedicated lesson/core topic**, not necessarily never mentioned.
- The comparison courses are Kubernetes-focused and assume prior container knowledge; LFS253 teaches container fundamentals from the ground up.
- Some LFS253 outlines include **Virtualization Fundamentals/Mechanisms** and **Runtime Security**; others do not. These are listed because they are generally absent as dedicated topics in the four comparison courses.
- Based on public outlines; not an official vendor comparison.

## Summary

Main incremental LFS253 topics: **container history, Linux building blocks, runtime comparisons, Docker Desktop/remote daemon, Docker Compose, Docker APIs, and practical Docker tips**.
